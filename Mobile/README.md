# Welcome to your Expo app 👋

This is an [Expo](https://expo.dev) project created with [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Configure the app by creating `Mobile/.env.local` from `Mobile/.env.example`. Set `EXPO_PUBLIC_SUPABASE_URL` and `EXPO_PUBLIC_SUPABASE_ANON_KEY` to the values from your Supabase project. Set `EXPO_PUBLIC_WEB_APP_URL` to the deployed web dashboard origin so native staff signup links point to the web signup flow.

3. Start the app

   ```bash
   npm start
   ```

`npm start` starts Expo in Expo Go mode. Open Expo Go on a phone connected to the same network and scan the QR code. OCR controls stay disabled in Expo Go because its native ML Kit dependency is not included there. To use OCR, set `EXPO_PUBLIC_ENABLE_OCR=true` in `.env.local` and start a development build with `npm run start:dev-client`.

The Expo server can also open the app in a

- [development build](https://docs.expo.dev/develop/development-builds/introduction/)
- [Android emulator](https://docs.expo.dev/workflow/android-studio-emulator/)
- [iOS simulator](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go), a limited sandbox for trying out app development with Expo

You can start developing by editing the files inside the **app** directory. This project uses [file-based routing](https://docs.expo.dev/router/introduction).

## Get a fresh project

When you're ready, run:

```bash
npm run reset-project
```

This command will move the starter code to the **app-example** directory and create a blank **app** directory where you can start developing.
